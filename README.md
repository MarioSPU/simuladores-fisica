# simuladores-fisica
# 🔬 Simuladores Interactivos de Física

Colección de simuladores web de física desarrollados con ayuda de Inteligencia Artificial para el aprendizaje visual de física en Bachillerato y Grado.

## 🚀 Simuladores Disponibles

### 1. Simuladores de Física de Bachillerato
* **Campos Vectoriales:** Representación visual de campo eléctrico y gravitatorio con superposición de cargas y masas.
* **Gravitación y Órbitas:** Cinemática, dinámicas y cálculo de energías en satélites.
* **Leyes de Kepler:** Movimiento elíptico, velocidad orbital y conservación del momento angular.
* **Ondas Transversales:** Ecuación de onda, frecuencia, número de onda y desfase.
* **Óptica Geométrica:** Formación de imágenes en lentes individuales.

### 2. Simulador de Sistemas de Lentes Delgadas (Avanzado)
* Trazado de rayos y cálculo analítico según la norma DIN.
* Configuración de múltiples lentes compuestas.
* Presets predefinidos: Lupa, Microscopio Compuesto, Telescopio Astronómico de Kepler y Telescopio de Galileo.

## 🛠️ Tecnologías
* HTML5 / CSS3
* JavaScript (Canvas API)
